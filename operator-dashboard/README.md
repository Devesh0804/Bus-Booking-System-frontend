# Operator Dashboard

This is a standalone frontend-only dashboard for bus operators. It does not connect to the backend and does not modify the existing passenger application.

## Files

- `index.html` contains the dashboard markup.
- `styles.css` contains all responsive layout and visual styles.
- `app.js` contains local UI behavior for adding buses, creating recurring trip schedules, switching sections, and previewing dashboard data.

## Run

Open `index.html` in a browser, or serve this folder with any static server.
